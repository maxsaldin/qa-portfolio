#  📌 Тестовое задание (курс Николая Кротова)

> Задание имитирует типовое тестовое, которое дают на собеседованиях Junior QA.  
> Выполнено в рамках курса «Ручное тестирование ПО», 2025 г.

---

1. Составьте Test Suite для функционального тестирования формы авторизации. Форма имеет два поля для ввода: Логин "Login" и пароль "Password", а также кнопку "Sign in" для подтверждения входа в систему.

2. Составьте позитивный и негативный Test Case для функциональной проверки формы обратной связи. Форма имеет обязательные поля "Name", "Email", "Message", а также кнопку "Send". После нажатия на кнопку выводится сообщение о результате операции.

3. Кратко опишите процесс проведения Compatibility Testing сайта по следующим критериям: операционная система, разрешение экрана, браузер.

4. Составьте чек-лист для проведения Smoke Testing плеера, используемого на сайте https://www.youtube.com.

5. Найдите и оформите баг-репорт, используя методику Exploratory Testing, на сайте [https://guru.gahacking.ru/](https://guru.qahacking.ru/).

## 📋 1. Test Suite — Форма авторизации


---

> Все тест-кейсы выполнены в соответствии с требованиями: проверка успешного входа, повторной авторизации, обработки пустых и невалидных данных.

| ID | Название тест-кейса                                        | Тип       |
|----|------------------------------------------------------------|-----------|
| 1  | Успешный вход с зарегистрированным логином и паролем       | Позитивный |
| 2  | Успешная повторная авторизация после разлогина             | Позитивный |
| 3  | Ошибка при попытке входа без заполнения логина и пароля    | Негативный |
| 4  | Ошибка входа при использовании несуществующего логина      | Негативный |
| 5  | Ошибка входа при вводе неверного пароля                    | Негативный |

---

#### **ID: 1 — Успешный вход с зарегистрированным логином и паролем**

- **Шаги**:
 1. Ввести зарегистрированный логин: `Fishman777`
 2. Ввести соответствующий пароль: `12345`
 3. Нажать кнопку ввода
- **Ожидаемый результат**: Авторизация прошла успешно → пользователь перенаправлен на главную страницу.

#### **ID: 2 — Успешная повторная авторизация после разлогина**

- **Шаги**:

- **Ожидаемый результат**: Повторная авторизация прошла успешно → пользователь снова перенаправлен на главную страницу.

#### **ID: 3 — Ошибка при попытке входа без заполнения логина и пароля**

## 🧭 3. Compatibility Testing

---

> Тестирование совместимости или конфигурационное тестирование. 
Разделяется на кроссбраузерное и кроссплатформенное.
Проводится для того чтобы проверить работу сайта в определенном окружении. 

#### Критерии тестирования:

1. **Операционная система**:  
   - Windows 10/11  
   - macOS Sonoma  
   - Android 13  
   - iOS 17  

2. **Разрешение экрана**:  
   - 1920×1080 (Full HD)  
   - 1366×768 (HD)  
   - 360×640 (мобильное устройство)  

3. **Браузер**:  
   - Google Chrome 
   - Mozilla Firefox
   - Safari
   - Microsoft Edge

## 📋 4. Чек-лист — Smoke Testing YouTube

---

> Smoke Testing — это минимальный набор тестов, который позволяет быстро убедиться, что основные функции работают.

#### Чек-лист для Smoke Testing видео-плеера YouTube:

1. Воспроизведение видео по клику play  
2. Изменение громкости ползунком/скроллбаром  
3. Пауза при клике на экран или нажатии пробела  
4. Переключение в режим полного экрана  
5. Перемотка видео при клике по полосе  
6. Открытие меню настроек  
7. Включение/выключение субтитров  
8. Переключение в режим широкого экрана  
9. Переключение плеера в свёрнутый режим  
10. Настройка качества видео

## 📋 5. Баг-репорт — Exploratory Testing [https://guru.gahacking.ru/](https://guru.qahacking.ru/)

---

> Exploratory Testing — это исследовательское тестирование, при котором тестировщик свободно исследует сайт, не имея предварительных инструкций, и ищет ошибки.


- **Описание**: Блоки «Свежие посты» и «Популярное» выровнены по одному уровню, но блок «Популярное» опечатан в названии. Блок крутится против часовой стрелки по мере опускания страницы вниз.

- **Шаги воспроизведения**:
 1. Открыть страницу: [`https://guru.gahacking.ru/index.php/news?start=6`](https://guru.qahacking.ru/index.php/news?start=6)
 2. Прокрутить страницу вниз

- **Ожидаемый результат**:  
  Блоки «Свежие посты» и «Популярное» выровнены по одному уровню.  
  Название блока — «Популярное».  
  Блок не вращается при прокрутке.

- **Фактический результат**:  
  Блоки выровнены по одному уровню.  
  Название блока — «Пупулярное» (опечатка).  
  Блок крутится против часовой стрелки по мере опускания страницы вниз.

- **Окружение**:  
  - Браузер: Google Chrome: 139.0.7258.66 (Официальная сборка) (64 бит)
  - ОС: Windows 10  
  - Разрешение: 1920×1080

- **Приоритет**: Средний
